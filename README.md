# 통역/번역/강의 정산 대시보드 Ver. 1.1 (배포용)

## 사용 및 개인정보 안내 ## 
- 이 배포본은 개인 업무 내역 / 수입 데이터가 포함되지 않은 빈 템플릿입니다.
- 모든 기록은 사용자의 브라우저 로컬 저장소에 저장됩니다. 계정, 서버 저장, 기기 간 동기화는 없습니다.
- 같은 브라우저 프로필에서 여러 사람이 함께 사용하면 기록이 섞일 수 있습니다.
- 백업 JSON/CSV에는 개인정보와 수입 정보가 포함될 수 있으므로 GitHub 저장소에 올리지 마세요.
- 기존 데이터를 옮길 때는 본인만 접근 가능한 백업 파일을 사용하세요.
