# 통역 정산 대시보드 (배포용)

## GitHub Pages 배포
1. GitHub에서 Public 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/(root)`를 선택하고 저장합니다.
4. 배포가 완료되면 표시되는 사이트 주소를 엽니다.

## 사용 및 개인정보
- 이 배포본은 개인 업무/수입 데이터가 포함되지 않은 빈 템플릿입니다.
- 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 계정, 서버 저장, 기기 간 동기화는 없습니다.
- 같은 브라우저 프로필에서 여러 사람이 함께 사용하면 기록이 섞일 수 있습니다.
- 백업 JSON/CSV에는 개인정보와 수입 정보가 포함될 수 있으므로 GitHub 저장소에 올리지 마세요.
- 기존 데이터를 옮길 때는 본인만 접근 가능한 백업 파일을 사용하세요.
